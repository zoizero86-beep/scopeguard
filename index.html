Paste the scope you agreed on and the client message you just received. The check runs entirely in this browser tab with an open-weight embedding model — no upload, no API key, no server. Useful when the text is under NDA and you cannot paste it into a cloud tool.

Idle. The model (~23 MB, quantized) downloads once from a public model hub on first run and is then served from the browser cache.

ScopeGuard is a static page. It uses transformers.js and the open-weight model Xenova/all-MiniLM-L6-v2 (ONNX, quantized) through WebAssembly. Similarity is cosine similarity between sentence embeddings. Nothing you paste leaves the tab — you can watch the network panel stay silent after the model loads.

MIT licensed. No accounts, no telemetry, no analytics.
